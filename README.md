# Project summary

Malik McQueen: Lost in the City is a kid-friendly WPF game inspired by the Breakout tutorial. Malik becomes separated from his friends in Radiator Springs and must clear city obstacles with a bouncing tire to make his way home. This repository contains the project setup, planning documents, prepared assets, screenshots, and Git history required for Week 10.

# How to open and run the project

1. **Editor:** Visual Studio 2022
2. **Workload:** .NET Desktop Development
3. **Open:** `src/DungeonGame/DungeonGame.sln`
4. Press **F5** or click **Start**.
5. The empty WPF application should open successfully.
